# Security Policy

## Supported Versions

This repository is primarily an educational resource containing computer science fundamentals, notes, examples, and reference implementations.

Security updates are provided for the **latest version of the repository**.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest         | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in any code or implementation contained in this repository, please report it responsibly.

### How to Report

Please **do not create a public GitHub issue** for security vulnerabilities.

Instead, report the vulnerability privately through the repository's **GitHub Security Advisories** feature, if available.

When reporting a vulnerability, please include:

* A clear description of the vulnerability
* The affected file, feature, or implementation
* Steps to reproduce the issue
* Potential impact
* Any suggested fix, if available

### What to Expect

I will review the report and acknowledge it as soon as reasonably possible.

If the vulnerability is confirmed:

* The issue will be investigated and addressed where appropriate.
* A fix or clarification will be provided when possible.
* Credit may be given to the reporter, with their permission.

If the report is determined not to be a security vulnerability, I will provide an explanation where appropriate.

Thank you for helping keep this project safe and reliable.
